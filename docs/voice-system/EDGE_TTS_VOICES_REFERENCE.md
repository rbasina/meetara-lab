## Voice Selection Logic

### Automatic Selection
The system automatically selects voices based on:
1. **Domain Category**: Each category has pre-assigned voices
2. **Emotional Context**: Adjusts voice selection based on detected emotion
3. **User Preferences**: Can be overridden by user settings
4. **Availability**: Falls back to local TTS if Edge TTS unavailable

### Fallback Chain
```
Edge TTS (Cloud) 
    ↓ (if failed)
Piper TTS (Local, 120MB)
    ↓ (if failed)
Bark TTS (Local, 5.1GB) [optional]
    ↓ (if failed)
PyTTSx3 (System)
```

## Technical Details

### Requirements
- **Internet Connection**: Required for Edge TTS
- **No API Key**: Edge TTS is free to use
- **Quality**: 90/100 (excellent)
- **Latency**: ~100-500ms depending on internet speed
- **Languages**: English (US, GB, AU, CA) configured

### Privacy Note
Text is sent to Microsoft servers for Edge TTS generation. For privacy-sensitive applications, use local TTS (Piper/Bark) by disabling Edge TTS.

## Configuration

### Enable/Disable Edge TTS
**File**: `core/core_components/tts_manager.py`

```python
self.cloud_settings = {
    "edge_tts_enabled": True,  # Set to False to disable
    "cloud_first_priority": True,  # Prioritize cloud over local
}
```

### Add New Voices
To add new Edge TTS voices, update `voice_categories` in `tts_manager.py`:

```python
"category_name": {
    "edge_voices": ["en-US-NewVoice1", "en-US-NewVoice2"],
    # ... other settings
}
```
