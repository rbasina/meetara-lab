## 🚀 **Quick Start**

### **1. Clone and Setup**
```bash
git clone https://github.com/meetara-ai/meetara-lab.git
cd meetara-lab
pip install -r requirements.txt
```

### **2. Create Universal Models**
```bash
# Create complete universal model ecosystem
python scripts/gguf_factory/working_enhanced_factory.py

# Download base models foundation
python scripts/gguf_factory/download_base_models.py
```

### **3. Launch Trinity UI**
```bash
# Start comparison interface
cd ui
python meetara_comparison_backend.py
# Open http://localhost:8000
```

### **4. Google Colab Integration**
- **[Open in Colab](notebooks/meetara_lab_production_colab.ipynb)** - Complete training pipeline
- **[Production Launcher](notebooks/meetara_production_launcher.ipynb)** - Full ecosystem deployment
